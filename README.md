# Warehouse Management System

## Overview

Warehouse Management System is a responsive and user-friendly web application designed to simplify warehouse administration, inventory monitoring, tenant management, lease tracking, payment handling, and support operations. The project provides an organized platform for managing daily warehouse activities through multiple interconnected modules and dashboards.

The system is developed using core front-end technologies such as HTML and CSS, focusing on simplicity, clean design, responsiveness, and easy navigation. It is suitable for academic projects, mini projects, and warehouse operation management demonstrations.

# Module Description

## 1. Home Dashboard

The main dashboard acts as the central navigation point of the system. It provides quick access to warehouse operations, reports, tenant management, and inventory handling.

## 2. Inventory Module

This module allows warehouse administrators to manage inventory records efficiently. Users can add inventory details and monitor warehouse stock.

## 3. Tenant Module

The tenant management system stores tenant details and organizes tenant-related records for warehouse administration.

## 4. Lease & Agreement Module

This section manages warehouse lease details, agreements, and rental information between tenants and warehouse management.

## 5. Payment Management

The payment section handles rent payments and transaction monitoring, helping maintain financial tracking.

## 6. Support System

The support module enables users to create tickets and monitor issues for better warehouse administration.

## 7. Reports Module

The reports section provides operational summaries and management reports for warehouse activities.
